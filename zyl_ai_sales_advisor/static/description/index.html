Get Started in 3 Steps

Up and running in minutes — no complex setup required

1
Install the Module
Go to Apps → AI Sales Advisor in your Odoo 18 instance and click Install.
2
Add Your AI API Key
Open AI Sales Advisor → Configuration → AI Settings. Enter your Google Gemini, OpenAI, or Anthropic API key. Select model and response preferences.
3
Open the Dashboard
KPIs, charts, Seasonal Heatmap, AI Chat, and Insight generation are immediately active with your live Odoo sales data.
